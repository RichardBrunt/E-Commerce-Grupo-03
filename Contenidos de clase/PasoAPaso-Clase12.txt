Docker Desktop for Windows
	Función: Plataforma completa de containerización para Windows
	Incluye: Docker Engine, Docker CLI, Docker Compose, Kubernetes
	
Visual Studio Code + Extensiones Docker
	Docker (Microsoft) - Extensión oficial


1: Instalar Docker Desktop
Descargar e instalar Docker Desktop para Windows.
	Habilitar WSL 2 (recomendado) durante la instalación.
	WSL 2 (Windows Subsystem for Linux, versión 2) de Microsoft que permite ejecutar un entorno Linux completo directamente en Windows sin necesidad de máquinas virtuales tradicionales. Está especialmente diseñado para desarrolladores que necesitan herramientas Linux en Windows.
	
2: Instalar la extensión Docker en VSCode
Abrir VSCode.
Buscar la extensión "Docker" (desarrollada por Microsoft). ms-azuretools.vscode-docker
Instalar y reiniciar VSCode.
